# فرایند و مدارک عضویت

## مدارک مورد نیاز برای تشکیل پروند و عضویت در تعاونی مسکن نخبگان استان تهران 
- تصویر کارت ملی و صفحه اول شناسنامه؛
- معرفی‌نامه یا گواهی اشتغال دانشگاهی؛
  - حکم پیمانی، رسمی آزمایشی یا رسمی هیئت علمی فعال در زمان عضویت
- مستند احراز شرایط جامعه هدف؛
- فرم تکمیل‌شده عضویت؛
- تعهدنامه‌های مصوب؛
- رسید پرداخت‌های اولیه، در صورت تصویب.


## وضعیت‌های پرونده
| وضعیت | توضیح                             |
|---|-----------------------------------|
| پیش‌نویس | درخواست هنوز تکمیل نشده است       |
| در حال بررسی | مدارک توسط دبیرخانه بررسی می‌شود  |
| نیازمند اصلاح | نقص یا ابهام در مدارک وجود دارد   |
| تأیید اولیه | شرایط اولیه احراز شده است         |
| عضو فعال | مراحل قانونی و مالی تکمیل شده است |
