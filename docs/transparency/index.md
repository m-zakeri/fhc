# شفافیت و گزارش‌ها

مرکز شفافیت برای انتشار اطلاعاتی طراحی شده است که اعضا طبق قوانین و مصوبات حق دسترسی به آن دارند، بدون افشای اطلاعات شخصی یا محرمانه.

## سیاست پیشنهادی انتشار
برای هر گزارش، تاریخ انتشار، دوره گزارش، مسئول تهیه، مرجع تصویب و شماره نسخه درج شود. اطلاعات شخصی، شماره حساب‌ها، اطلاعات تجاری محرمانه و داده‌های دارای محدودیت قانونی منتشر نشوند.
